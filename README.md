# batty-ffxiv-status

Machine-published snapshot for [battydev.com/ffxiv](https://battydev.com/ffxiv).

`ffxiv.json` on the `data` branch is written nightly by batty-mac and force-pushed as a
single amended commit, so this branch holds one commit rather than one per night.

Contents are filtered before publication: current state for every tracked character,
and time-axis data (level progression, dated achievements, collection deltas,
last-active) only for characters who opted in. Full history stays on batty-mac.
